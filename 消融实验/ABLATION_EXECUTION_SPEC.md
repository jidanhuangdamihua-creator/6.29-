细则:

- **P1 冻结的定义**:仅冻结 conv1、conv2、conv3 的 kernel 和 bias。RevIN 的 γ 和 β、预测头、其余可训练参数照常更新。运行结束后断言冻结层的参数与初始值逐元素相等。

- **P3 均匀融合**:使用与 F4 完全相同的 3 个入选源和 3 个源模型,仅把 α 改为 1/3。
- **共享初始化(配对设计的关键)**:对同一个"条件 × 种子",
  - F3、F4、P1、P3 共用同一个 Stage A 缓存(入选源、距离、源模型、融合参数、源侧缩放参数);

- 无 RevIN 的配置(F1、F3):输入只经 Min–Max 缩放,预测输出不做输出恢复。

## 6. 统计分析(在 `analysis/` 中独立实现)

### 6.1 约定
- 记号 **X–Y** 表示配置 X 相对于配置 Y。相对改进率:`RI = (E_Y − E_X) / E_Y × 100%`,E 为该条件下 5 个种子的平均误差。RI 为正表示 X 更好。
- 先逐条件计算 RI,再对 12 个条件求算术平均。
- RMSE 与 sMAPE **分别**分析、分别做多重校正。
- 胜/负:RI > 0 记胜,RI < 0 记负,RI = 0 记平(单独列出)。
- 检验:双侧配对 Wilcoxon 符号秩(`scipy.stats.wilcoxon`,`zero_method="wilcox"`,`method="auto"`;记录实际使用的方法)。
- 置信区间:对 12 个条件的 RI 做 100,000 次**百分位 bootstrap**,有放回重抽 12 个条件,取平均值的 2.5% 和 97.5% 分位。固定随机数种子 `20261001`。
- 多重校正:Holm,仅在预先规定的比较族内进行。
- 所有计算必须有单元测试:用手算的小例子验证 RI、胜/负、Holm、bootstrap(固定种子可复现)。

### 6.2 比较族

**族 A:核心机制(2×2),5 项比较**

| 比较 | 含义 |

| F4–F3 | 有初始化时 RevIN 的效应 |

对 12 个条件的 `I_c` 做 Wilcoxon(检验是否偏离 0)和 bootstrap CI。

### 6.3 描述性补充(不做推断)

### 9.2 入口

### 9.3 断点续跑与完整性
- 每个 cell 用**原子写入**(先写临时文件再重命名),完成后写 `DONE.json`(含产物 SHA256)。
- 重启时跳过已有有效 `DONE.json` 且哈希校验通过的 cell。
- 失败的 cell 记录错误并继续,最后统一汇总失败清单;失败的 cell 最多自动重试一次,重试用同一种子。
- 每个 Phase 结束时生成完整性审计,任何缺失都要明确列出。

### 9.4 必需的测试(`tests/`)
- 缩放参数只由目标训练窗口拟合,源选择用的 Min–Max 单独拟合,二者互不混用。
- 源选择窗口、缩放拟合区间不包含任何测试日期。
- 逆距离权重和为 1、均匀权重全为 1/K、K=1 时 α=[1]。
- 冻结配置训练后卷积层参数不变;可训练配置的卷积层参数发生变化。
- 同一"条件 × 种子"下,各配置的非融合层初始值和训练数据顺序一致。
- RMSE 与 sMAPE 对小例子的手算值一致,含分母为 0 的情形。
- 统计模块:RI、胜/负、Holm、bootstrap 的手算对照。
- 数据文件哈希校验函数。

## 12. 默认决策规则

### 12.1 论文规范与代码不一致时
- 第三章和第四章的**明文规定**优先(例如 Huber 损失、K=3、ℓ=30、50 epoch、EMA 0.99、batch size 16)。

### 12.2 其他
- 数据缺失、候选源不足、某 cell 训练发散:不要删除,保留记录;统计分析时若某条件缺 cell,该条件在相应比较中标记为缺失并在表注说明,不得悄悄用其他值填充。
- 随机性:所有随机行为(初始化、shuffle、Random-3 抽取、bootstrap)都必须由显式种子驱动并记录。
- 数值精度:float32,与正式实验一致。
- 日志:每个进程写独立日志到 `logs/`,不要把大量输出打印到终端。
