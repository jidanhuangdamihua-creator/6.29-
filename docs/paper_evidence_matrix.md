## 使用规则

- 任何“已确认/ALIGNED”结论，必须给出 Evidence ID + Page。
- 仅工程可证、论文未证的结论，Evidence Type 必须标注为 inference 或 faithful paraphrase。
- 与 split 绝对边界有关的结论，若无新增页码证据，保持 PARTIAL/TODO。
